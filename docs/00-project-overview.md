# 项目概览

## 项目名称
IronLogic

## 项目定位
一款专业健身记录 App，核心聚焦：

- 渐进超负荷
- 周期化训练
- 模板训练与自由训练并存
- 训练序列推进
- 数据驱动的长期训练追踪

## 技术栈
- 前端：Flutter
- 后端：Spring Boot
- 数据库：PostgreSQL
- ORM：MyBatis-Plus
- 数据迁移：Flyway

## 当前目标
完成 MVP 架构设计与工程骨架搭建，逐步实现训练记录闭环。

## MVP 核心闭环
1. 用户创建训练计划
2. 用户创建 Block 和 SessionTemplate
3. 系统从模板生成训练
4. 用户记录实际训练
5. 系统保存训练数据
6. 系统推荐下一次训练
