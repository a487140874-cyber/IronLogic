# 需求说明

## 核心需求

### 1. 训练计划
用户可以创建训练计划 Program。

### 2. 阶段管理
Program 下可包含多个 ProgramBlock，例如：
- 增肌期
- 增力期
- 减脂期
- 减载期

### 3. 训练日模板
每个 Block 下可配置多个 SessionTemplate。

### 4. 动作模板
每个 SessionTemplate 下可配置多个 SessionExerciseTemplate，包括：
- 动作
- 组数
- 次数
- 重量
- 休息时间
- 渐进规则

### 5. 实际训练
系统支持：
- 从模板生成训练
- 手动自由训练

### 6. 渐进超负荷
系统支持：
- 固定增重
- 百分比增重
- 双重渐进
- 失败回退
- 减载

### 7. 训练推进
系统优先按训练序列推进，而不是按自然周日期推进。

## 非功能需求
- 可扩展
- 可维护
- 模块化
- 低学习成本
- 保持 MVP 边界清晰
